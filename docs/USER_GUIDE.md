# Руководство пользователя

## Привязка кабинета Ozon

1. `/bind`
2. Введи название магазина (любое — для удобства)
3. Введи **Client ID** из личного кабинета Ozon Seller → Настройки → API
4. Введи **API-ключ** (будет зашифрован и сохранён безопасно)

Сообщение с API-ключом автоматически удаляется после привязки.

В любой момент можно добавить ещё кабинетов — повтори `/bind` с другим названием.

## Управление кабинетами

`/sellers` — показывает список всех привязанных кабинетов.

## Загрузка товаров

1. `/upload_products` — получишь XLSX-шаблон
2. Заполни в Excel:
   - **SKU (артикул)** — уникальный артикул продавца
   - **Название** — название товара
   - **Category ID** — id категории на Ozon
   - **Цена (₽)** — целое число рублей (можно с копейками через запятую)
   - **Старая цена (₽)** — для скидок (опционально)
   - **Штрих-код**, **Вес (г)**, **Описание** — опционально
3. Сохрани файл и отправь боту как документ
4. Бот поставит загрузку в очередь, в конце пришлёт результат

Максимум 5000 товаров за раз. Если файл содержит ошибки — получишь XLSX-файл с указанием проблемных строк.

## Проверка статуса

`/status` — показывает последние 10 операций с их статусом (⏳ pending, 🔄 running, ✅ completed, ⚠️ partial, 🔴 failed).

## Список товаров

`/products` — показывает первые 20 товаров из активного кабинета.

## Справка

`/help` — список всех команд.

## Безопасность

- API-ключи шифруются (Fernet) перед сохранением в БД
- Сообщения с ключами удаляются автоматически
- Только владелец Telegram ID имеет доступ к своим кабинетам
- Webhook защищён secret_token в URL

## Если что-то пошло не так

Любая ошибка приходит в чат в понятном виде:
- 🔴 **что** произошло
- 💡 **что** делать (retry / перепривязать / проверить данные)
- 🆔 **correlation_id** для поиска в логах (если обратишься в поддержку)
